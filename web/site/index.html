        Scripting
        

          
The page exposes window.lisaAuto. In the browser console:

          
await lisaAuto.boot('/media/disk.dc42');
lisaAuto.pause();                    // stop real-time running
lisaAuto.type('hello\n');
await lisaAuto.click(600, 216);      // Lisa pixels
await lisaAuto.run(2000);            // 2 s of Lisa time
lisaAuto.screenshot();               // PNG data URL
lisaAuto.ascii();                    // the screen as text
